# Telegram AI Voice Assistant

A sophisticated Telegram bot with full voice interface, multi-AI model support, and encrypted data storage.

## 🌟 Features
- **Full Voice Interface**: Voice message recognition & speech synthesis
- **Multi-Model AI**: GPT-3.5 Turbo, Gemini Flash, Mistral via OpenRouter
- **Context Memory**: Remembers conversation history (last 10 messages)
- **Encrypted Logs**: User data protected with Fernet encryption
- **Admin System**: User management, ban system, log export
- **Background Tasks**: Inactivity monitoring, auto-save, failover

## 🛠 Tech Stack
- **Python 3.11+**
- **pyTelegramBotAPI** - Telegram Bot framework
- **OpenRouter API** - Multi-model AI access
- **SpeechRecognition + gTTS** - Voice processing
- **Cryptography** - Data encryption
- **FFmpeg** - Audio conversion
